# 캡슐 CAPSULE · 랜딩 페이지

> 같이 공부하고 싶은 **AI 공부 메이트**, 캡슐의 사전예약 랜딩 페이지입니다.

혼자 공부하면 30분도 버티기 힘들죠. 스터디위드미 영상은 나를 보고 반응하지 않고, 디스코드 모각공은 시간을 맞춰야 해요.
캡슐은 노트북 웹캠으로 나를 보고 반응하는 캐릭터와 함께 공부하는 서비스예요. 딴짓하면 캐릭터가 장난스럽게 말을 걸고, 공부한 시간만큼 캐릭터와 가까워져요.

이 저장소는 캡슐을 소개하고, 사용자가 **보고 싶은 스터디룸에 투표**한 뒤 **사전예약**까지 하도록 이끄는 페이지예요.
캡슐은 2026년 12월 기말고사 시즌에 웹으로 오픈합니다.

<br />

## 페이지 흐름

```
랜딩  →  스터디룸 투표  →  작품 상세  →  캐릭터 수요조사  →  사전예약  →  사전예약 완료
 /         /rooms         (카드)          /survey          /preorder        /done
```

| 페이지 | 주소 | 설명 |
| --- | --- | --- |
| **랜딩** | `/` | 캡슐 소개. 혼자 공부할 때의 고민 → 캡슐의 사용 방법 3단계 → 스터디룸 미리보기 순서로 보여줘요. 하단 갤러리에서는 작품 포스터들이 랜덤한 순서로 끝없이 흘러내려요. |
| **스터디룸 투표** | `/rooms` | 9개 스터디룸 중 같이 공부하고 싶은 룸을 골라요. 투표한 룸은 사전예약하면 무료로 열어줘요. |
| **작품 상세** | (투표 페이지 위 카드) | 포스터를 누르면 그 자리에서 포스터가 커지며 상세 카드가 열려요. **[이 스터디룸 투표하기]**로 투표해요. 룸은 하나만 고를 수 있어요. |
| **캐릭터 수요조사** | `/survey` | 앞으로 만들 스터디룸을 위해 원하는 관계·성격·세계관을 고르고(복수 선택), 원하는 캐릭터를 자유롭게 적어요. 답하지 않으면 **[건너뛰고 사전 예약하기]**로 넘어갈 수 있어요. |
| **사전예약** | `/preorder` | 이메일, 나이, 지금 공부하는 방식을 입력하고 약관에 동의해요. 약관 **보기**를 누르면 아래에서 요약 시트가 올라와요. 이메일 형식이 맞고 필수 약관에 동의해야 버튼이 활성화돼요. |
| **사전예약 완료** | `/done` | 투표한 작품의 포스터와 제목을 보여주고, 인스타그램 계정과 처음으로 돌아가기 버튼을 제공해요. |

페이지 사이는 앱처럼 옆으로 밀려 들어오는 전환으로 이어지고, 뒤로가기를 누르면 보던 위치로 돌아가요.
투표한 룸과 수요조사 답변은 페이지를 오가도 유지돼요. 새로고침하면 초기화돼요.

<br />

## 기술 스택

- **React 19** + **TypeScript** + **Vite**
- 라우팅·애니메이션 라이브러리 없이 구현
  - 라우팅: `pushState` 기반 자체 훅 (`useRoute`)
  - 페이지 전환·포스터 morph: View Transitions API (미지원 브라우저는 페이드로 대체)
  - 모달·시트: 네이티브 `<dialog>`
- 린트: oxlint
- 폰트: Pretendard (CDN)

<br />

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm run lint     # oxlint
```

<br />

## 폴더 구조

```
src/
├── pages/        페이지 단위 컴포넌트 (Landing, Rooms, Survey, Preorder, Done)
├── components/   랜딩 섹션(Hero, Problem, Steps, Rooms, Notice, Footer)과
│                 공용 UI(RoomSheet, TermsSheet, Checkbox)
├── hooks/        useRoute(라우팅·전환), useReveal(스크롤 등장),
│                 useAnimatedDialog(시트 닫힘 애니메이션), useHeroExitFallback
├── data/         페이지에 들어가는 내용 (아래 참고)
├── assets/       Figma에서 내보낸 이미지
└── styles.css    전역 스타일
```

디자인은 Figma의 iPhone 17 프레임(가로 402px)을 기준으로 해요. `styles.css`의 `--u` 값이 디자인 1px을 화면 폭에 맞게 바꿔서, 320px 휴대폰부터 402px까지 같은 비율로 보여요. 더 넓은 화면에서는 402px 폭으로 가운데에 놓여요.

## 내용 수정하기

문구나 항목은 대부분 `src/data/`에서 바꿀 수 있어요.

| 파일 | 내용 |
| --- | --- |
| `rooms.ts` | 스터디룸 목록 (제목, 설명, 포스터, 태그). 여기에 추가하면 투표 페이지와 랜딩 갤러리에 같이 반영돼요. |
| `survey.ts` | 수요조사 항목 (관계·성격·세계관 칩) |
| `preorder.ts` | 나이 선택지, 공부 방식 항목, 약관 동의 항목과 약관 요약 문구 |

<br />

## 배포할 때

- `/rooms`, `/survey` 같은 주소에서 새로고침해도 열리도록, 호스팅에 **SPA fallback**(모든 경로를 `index.html`로 연결) 설정이 필요해요.
