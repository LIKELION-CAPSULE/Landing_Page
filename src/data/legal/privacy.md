캡슐 팀(이하 '팀')은 캡슐 소개 페이지(이하 '랜딩페이지')의 개인정보 처리 내용을 다음과 같이 안내합니다. 앱에서의 회원가입·대화 정보 처리는 앱의 개인정보처리방침에서 별도로 안내합니다.

### 제1조 (처리 목적과 현재 수집 범위)

1. 랜딩페이지의 방문 경로, 버튼·데모 이용 현황, 화면 이용 흐름을 분석하여 소개 내용과 사용성을 개선합니다.
2. 현재 랜딩페이지에서는 이메일 입력, 투표, 사전예약, 설문 제출을 받지 않습니다. 데모는 실제 카메라·마이크를 사용하지 않습니다.

### 제2조 (처리하는 정보와 수집 방법)

| 구분 | 정보 | 수집 방법·용도 |
| --- | --- | --- |
| 방문·클릭 분석 | 페이지 방문 시각·주소, CTA 클릭, 데모 답장 선택·무응답 반응, 링크 공유·복사 방식, 메이트 소개 노출 | Mixpanel SDK로 이벤트와 정해진 속성을 전송하여 이용 현황 분석 |
| 브라우저 식별·환경 | 임의 생성한 익명 방문자 ID, 기기·브라우저·운영체제 정보, 화면 크기, 유입 페이지 정보 | Mixpanel SDK가 수집하며 식별자 등은 브라우저 localStorage에 저장. 랜딩에서 이름·이메일이나 앱 계정과 연결하지 않음 |
| 유입 정보 | URL의 UTM 캠페인 정보, 유입 경로, 앱 연결 링크의 친구 초대 코드(ref) | Mixpanel의 유입 분석 및 앱 연결. utm_*와 ref는 앱 링크에 그대로 전달 |
| 세션 녹화 | 화면 구성과 클릭·스크롤 등 페이지 안의 상호작용 | Mixpanel 세션 재현 기능으로 이용 흐름 분석. 브라우저에서 녹화가 가능한 세션의 수집 비율은 100%로 설정 |

세션 녹화는 화면 전체를 촬영한 동영상이 아니라 페이지 구조와 상호작용을 재현하는 기록입니다. 입력값과 화면 텍스트는 SDK 기본 가림 설정을 사용하며 영상·오디오 요소는 수집 대상에서 차단합니다. 방문자의 카메라 영상·마이크 음성을 녹음하거나 녹화하지 않습니다.

Mixpanel 전송 요청에는 네트워크 통신에 필요한 IP 주소가 수반되며 SDK 기본 설정에 따라 대략적인 지역 정보가 산출될 수 있습니다. 별도의 실명 식별 정보를 이벤트 속성으로 보내지 않습니다.

### 제3조 (보유 및 이용 기간)

1. 방문·클릭 이벤트와 유입 정보: [Mixpanel 프로젝트의 이벤트 보유 기간] 동안 보관한 후 파기합니다.
2. 세션 녹화: [Mixpanel 프로젝트의 세션 녹화 보유 기간] 동안 보관한 후 파기합니다.
3. 브라우저 localStorage의 식별 정보는 이용자가 해당 사이트 저장 데이터를 지울 때까지 남을 수 있습니다. 브라우저 저장 정보 삭제가 이미 전송된 서버 기록의 삭제를 의미하지는 않습니다.
4. 과거 사전예약 시 제공된 정보는 신규 수집 없이 보존 중입니다. 기존 안내에 따른 보유 기준은 정식 출시 후 혜택 지급이 끝나는 날부터 6개월이며, 출시가 취소되면 취소 공지일로부터 30일 이내에 파기합니다. 이 기준의 적용 시점은 [기존 사전예약 정보의 보유 종료일]입니다. 법령에 따라 보존해야 하는 정보가 있으면 [보존 근거·항목·기간]에 따라 별도 보관합니다.

| 수탁자 | 업무 |
| --- | --- |

### 제6조 (localStorage 등 자동 수집 장치)

1. Mixpanel 분석은 쿠키 대신 localStorage 저장 방식으로 설정되어 있습니다. 익명 방문자 ID와 분석에 필요한 SDK 상태를 해당 브라우저에 저장합니다.
2. 이용자는 브라우저의 사이트 데이터 설정에서 이 사이트의 저장 정보를 삭제하거나 저장을 제한할 수 있습니다. 저장 정보만 지워도 이후 방문 시 식별자가 다시 생성될 수 있습니다.
3. 전송 자체의 거부 및 이미 전송된 정보의 처리 정지는 [분석·세션 녹화 거부 방법] 또는 아래 문의처로 요청할 수 있습니다.
